# I0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the I0 runnable monorepo scaffold for the Fudan study-room booking system without modifying the original course prompt or design mockup.

**Architecture:** Use a pnpm workspace with one NestJS API, two independent Vite React apps, shared TypeScript packages for contracts and design tokens, local Docker infrastructure, and a GitHub Actions CI workflow. The API exposes only the health and infrastructure contracts required for I0; business modules stay out of scope.

**Tech Stack:** Node.js 20, pnpm 9, TypeScript 5.4, NestJS 10, Prisma 5, React 18, Vite 5, Vitest/Jest, MySQL 8.4, Redis 7.2, MailHog, GitHub Actions.
